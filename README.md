# AI Cyber Threat Detection

## Overview

AI Cyber Threat Detection is a machine learning-based cybersecurity project designed to identify potential threats in network activity. The system uses a trained Random Forest model to analyze input features and classify traffic as either safe or suspicious.

## Features

* Machine Learning-based threat detection
* Random Forest classification model
* Flask API for prediction services
* Interactive Streamlit dashboard
* Model persistence using Joblib
* Clean and beginner-friendly project structure
